# 🌍 Smart Trip - AI Powered Travel Planner

Smart Trip is an AI-powered travel planning platform that generates personalized travel itineraries based on user preferences such as destination, budget, duration, travel style, and interests. The application leverages a Large Language Model (LLM) to create intelligent, day-wise travel plans and allows users to save and manage their trips.

---

## ✨ Features

- 🔐 User Authentication (Register/Login)
- 🤖 AI-generated personalized travel itineraries
- 📍 Destination search
- 💰 Budget-based trip planning
- 📅 Day-wise itinerary generation
- 👨‍👩‍👧‍👦 Traveler count support
- ❤️ Save and manage favorite trips
- 🗺️ Interactive map integration
- 📱 Responsive user interface

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/YarlagaddaJanaki/Smart-Trip.git
```

### 2. Navigate to Project

```bash
cd Smart-Trip
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 5. Configure Environment Variables

Create a `.env` file inside the `backend` folder.

Example:

```
PORT=5000

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=travel_planner

JWT_SECRET=your_secret_key

OLLAMA_HOST=http://127.0.0.1:11434
```

---

## ▶️ Running the Project

### Start Backend

```bash
cd backend
npm start
```

### Start Frontend

```bash
cd frontend
npm run dev
```
